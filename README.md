# Celestia-Bodies-DB
A relational database created and updated with psql, the CLI for PostgreSQL. <br>
This is one of the projects for the relational DB course on FreeCodeCamp. <br>
The "universe" DB is made of 5 tables. <br>
All tables have a primary key that uses a SERIAL type to auto-increment the value of each entry, and
4 of the 5 tables have a foreign key constraint to link the data to another table. <br>
The NOT NULL and UNIQUE constraints are also used in all tables.
